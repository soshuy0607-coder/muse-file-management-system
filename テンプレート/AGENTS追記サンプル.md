# 全体用 AGENTS.md への追記サンプル

導入時に、全体用 AGENTS.md（毎回読まれる運用マニュアル）へ以下の趣旨を
短く書き加える。詳細は書かず、監査ルール.md への案内にとどめるのが要点
（AGENTS.md 自体のサイズ上限は監査ルール14が警告で担保する）。

## 核ルール（例文）

- ファイル管理：`workspace/` 直下にファイルを置かない。プロジェクトは
  `workspace/projects/<プロジェクト名_テーマ>/` に置き、紐づくチャットの
  名前をフォルダ名と完全に一致させる。各プロジェクトは自己完結の固定構成
  （`INDEX.md`、`chat.json`、`files/`、`inputs/`、`hidden_files/`）とし、
  `projects/` 直下のファイルは `PROJECT_LIST.md` のみとする。ゴールとの
  紐付けはID参照のみとし、名前へ他の実体の名前を埋め込まない。
  プロジェクトやチャットの作成・改名時は、同じターンのうちに
  `PROJECT_LIST.md` とプロジェクトの `INDEX.md` / `chat.json` を更新し、
  監査を実行する：`python3 ~/workspace/監査コード/audit_file_storage.py`。
  ファイル構成に触れる活動の締めには監査を回し、正常時は報告しない。
  詳細ルール：`workspace/監査コード/監査ルール.md`。
