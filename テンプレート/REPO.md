# GitHubリポジトリ登録台帳

このプロジェクトに紐づく GitHub リポジトリの登録。
`github/` フォルダの中には、このファイルだけを置く。

- リポジトリ：owner/repository-name
- URL：https://github.com/owner/repository-name
- 既定ブランチ：main
- 公開範囲：private
- 同期元：files/配布版_v1.0.0
- 履歴：../../監査コード
- 目的：（任意。このリポジトリの役割を書く）

- 同期元は任意項目。プッシュ元フォルダを、プロジェクト直下からの
  相対パスで書く。
- 履歴は必須項目。ローカルの Git リポジトリ（履歴の置き場）の場所を、
  同じく相対パスで書く。監査は、その場所が実在し Git リポジトリ
  であることまで確認する。
- リポジトリ名・公開範囲・同期元が変わったら、同じターンのうちに
  このファイルを実態に合わせて更新すること。
